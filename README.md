## English

Hi, I'm Mourad — a self-taught software engineer with around a decade of experience building applications.

My professional work focuses on streaming products and cross-platform experiences, especially React Native for TV, mobile, and web platforms. Beyond application development, I enjoy working with Go and C++, learning Zig, and exploring how software works closer to the machine.

I'm particularly curious about compilers, runtimes, operating systems, and efficient AI inference. I learn best by building things, testing assumptions, and sharing the results.

### Projects I'm building in public

- **[Itar · إطار](https://github.com/mbougarne/itar)** — A C++20 focus engine for React Native TV applications. *Source beta; device testing in progress.*
- **[Modawana](https://github.com/mbougarne/modawana)** — Self-hosted publishing for writing, documentation, and learning paths, built with Go, React, and SQLite.
- **[Sama · سماء](https://github.com/mbougarne/sama)** — An open-source, self-hosted cloud management backoffice. *In development.*
- **[Zigide](https://github.com/mbougarne/Zigide)** — An experimental IDE written in Zig, built to learn the language and IDE internals.
- **[Geo Location Picker](https://github.com/mbougarne/geoLocationPicker)** — Accessible React components for countries and international dialing codes.

Much of my professional work lives in private client repositories. The projects here show what I choose to build, study, and share independently.

I'm happy to collaborate on open-source projects and help make technical knowledge more accessible in Arabic.
